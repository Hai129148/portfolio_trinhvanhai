# Portfolio Trịnh Văn Hải

Trang tĩnh song ngữ, không cần cài đặt. Mở `index.html` để xem hoặc xuất bản toàn bộ tệp lên GitHub Pages.

Trong repository GitHub, vào **Settings → Pages**, chọn triển khai từ nhánh chứa các tệp này và thư mục `/ (root)`. Địa chỉ mặc định của repository dự kiến là `https://hai129148.github.io/portfolio_trinhvanhai/`.

Dự án khách hàng được trình bày ẩn danh; hình minh họa không phải ảnh chụp ứng dụng thực tế.
